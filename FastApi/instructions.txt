How to setup the FastAPI application
Step 1: setup venv
    python -m venv .venv
    .venv\Scripts\Activate.ps1
    python -m pip install --upgrade pip

Step 2: install packages
    pip install "fastapi[standard]"

Step 3: run application
    fastapi dev main.py

Comments are left in every file, read main.py and search.py for more detailed explanations of things
