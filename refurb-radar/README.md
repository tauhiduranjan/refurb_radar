Refurb Radar 📡

Smart, streamlined platform that helps users find the best deals on refurbished tech across the internet

🚀 What We're Building
Refurb Radar eliminates the hassle of manually checking multiple sites for refurbished tech deals. Search once and instantly compare prices from trusted sellers like Amazon Renewed, Back Market, Best Buy Outlet, and more. Our mission is to make refurbished shopping faster, easier, and more trustworthy — helping cost-conscious consumers save money without sacrificing quality.
Whether you're a student hunting for a budget laptop or a gamer looking for a deal on last-gen hardware, Refurb Radar helps you shop smart — not hard.
✨ Key Features

 Smart Search - Compare refurbished listings for phones, laptops, consoles, and more
 Price Tracking - View historical pricing data and set alerts for deals
 Trusted Sources - Index listings only from verified, reputable sellers
 Clean Interface - Built for speed and clarity, on both desktop and mobile
 Deal Alerts - Get notified when prices drop on items you're watching
 Condition Filtering - Filter by refurb condition (Like New, Very Good, Good, etc.)
